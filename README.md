# AWS SAA-C03 Obsidian Study Vault

An [Obsidian](https://obsidian.md) vault for the **AWS Certified Solutions Architect - Associate (SAA-C03)** exam. It has 489 linked notes covering all 119 services on AWS's in-scope list, built for Obsidian's graph view.

> [!IMPORTANT]
> **This vault is fully AI-generated.** It was written and assembled by Claude, Anthropic's AI model, from the sources below. No person has reviewed it line by line, so it may contain mistakes. Check anything important against the [AWS documentation](https://docs.aws.amazon.com/).

Facts were checked against AWS documentation on 1 November 2026. AWS changes quickly, so some details will go out of date.

## What's inside

| Folder | Contents |
| --- | --- |
| `01 Exam` | Exam overview, the 4 domains, 14 task pages, exam traps and 38 scenario drills |
| `02 Maps` | Small linking files by category, which act as hubs in the graph |
| `03 Services` | One note per service or feature |
| `04 Concepts` | Cross-cutting ideas, such as high availability |
| `05 Comparisons` | Side-by-side tables and decision guides |
| `06 Architectures` | Patterns and case studies with Mermaid diagrams |
| `07 Reference` | Sources, corrections, service lifecycle status and limits |

## How to use it

1. Clone or download this repository.
2. In Obsidian, choose **Open folder as vault** and select it.
3. Start at `Home`, then press Ctrl+G to open the graph.

`07 Reference/How to Use This Vault` explains the graph filters and tags.
