# Amazon ECR

**ECR** - private docker registry on AWS. It stores and manages Docker images on AWS. It is fully integrated with [[Amazon ECS|ECS]] and backed by [[Amazon S3|S3]].

Access is controlled through [[AWS IAM|IAM]]. It supports image vulnerability scanning, versioning, image tags, image lifecycle…
