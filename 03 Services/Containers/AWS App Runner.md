# AWS App Runner

> [!warning] Closed to new customers
> In maintenance since 31 March 2026. AWS recommends Amazon ECS Express Mode.

> [!note] Exam scope
> Not on AWS's in-scope or out-of-scope list. The in-scope list is non-exhaustive, so treat this as background.

**App Runner** is a fully managed service that makes it easy to deploy web applications and APIs at scale. It automatically builds and deploys the web app. We don't need infrastructure experience (start with our source code or container image).

We can connect to database, cache and message queue services. It has automatic scaling, [[Elastic Load Balancing|load balancer]] and encryption.

Use cases: web apps, APIs, microservices, rapid production deployments.
