# SSM Run Command

- **SSM Run Command**

    It lets us to execute a script or just run a command. We can run command across multiple instances (using resource groups) and we don't need SSH. It can be integrated with [[AWS IAM|IAM]] & [[AWS CloudTrail|CloudTrail]] and can be invoked using [[Amazon EventBridge|EventBridge]].

    Command output can be shown in the AWS Console, sent to [[Amazon S3|S3 bucket]] or [[CloudWatch Logs]]. We can also send notifications to [[Amazon SNS|SNS]] about command status.
