# SSM Parameter Store

**SSM Parameter Store** - it is a secure storage for configuration and secrets (API keys, passwords, configurations …). It is serverless, scalable and durable. Also it is secure because we control access permissions using [[AWS IAM|IAM]].

**Parameters Policies** - allow us to assign a TTL to a parameter to force updating or deleting sensitive data such as passwords.
