# SSM Automation

- **SSM Automation**

    It simplifies common maintenance and deployment tasks of [[Amazon EC2|EC2 instances]] and other AWS services (e.g. restart instances, create an [[Amazon Machine Image|AMI]], [[EBS Snapshots|EBS snapshot]]).

    **Automation Runbook** - define actions performed on our EC2 instances or AWS resources.

    Automation can be triggered using:

    - AWS Console, [[AWS CLI]] or SDK
    - [[Amazon EventBridge|EventBridge]]
    - Using [[SSM Maintenance Windows|Maintenance Windows]]
    - [[AWS Config]]
