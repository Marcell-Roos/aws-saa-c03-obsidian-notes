# SSM Session Manager

**SSM Session Manager** - allows us to start SSH on our [[Amazon EC2|EC2]] and on-premises servers. No SSH access, [[Bastion Hosts|bastion hosts]] or SSH keys needed. Also if we want better security we can disable port 22.
