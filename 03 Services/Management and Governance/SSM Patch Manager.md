# SSM Patch Manager

- **SSM Patch Manager**

    It automates the process of patching managed instances (OS updates, applications updates, security updates). It supports [[Amazon EC2|EC2 instances]] and on-premises servers. Can scan instances and generate patch compliance.

    We can patch on-demand or on a schedule using [[SSM Maintenance Windows|Maintenance Windows]].
