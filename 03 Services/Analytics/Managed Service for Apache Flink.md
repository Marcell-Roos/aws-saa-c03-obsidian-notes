# Managed Service for Apache Flink

> [!note] Exam scope
> Not on AWS's in-scope or out-of-scope list. The in-scope list is non-exhaustive, so treat this as background.

**KDA for Apache Flink**

Supports building and running Apache Flink applications. We get automatic provisioning compute resources, parallel computation and automatic scaling and automatic backups. Flink does not read from [[Amazon Data Firehose|KDF]].

> Flink is a powerful open-source stream processing framework that provides advanced capabilities for managing state, fault tolerance, and complex event processing.

This is the former Kinesis Data Analytics for Apache Flink. **The SQL version shut down on 27 January 2026**, so its source section was removed. Older questions may mention "Kinesis Data Analytics", which now means this service. It's written with Java, Scala, Python or SQL through Flink.
