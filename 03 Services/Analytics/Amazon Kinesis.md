# Amazon Kinesis

**Kinesis** is a managed service which collect, process and analyze real-time streaming data at any scale.

Kinesis components:

- **[[Kinesis Data Streams]] (KDS)** - collect and process large streams of data records in real time.
- **[[Amazon Data Firehose]]** (formerly Kinesis Data Firehose) - loads streaming data into [[Data Lakes|data lakes]], data stores, and analytics services.
- **[[Managed Service for Apache Flink]]** (formerly Kinesis Data Analytics) - analyzes streaming data using Apache Flink.
- **[[Amazon Kinesis Video Streams|Kinesis Video Streams]]** - streams and process video in real time.
