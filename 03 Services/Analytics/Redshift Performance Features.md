# Redshift Performance Features

- **Concurrency Scaling** adds temporary capacity for bursts of queries.
- **Enhanced VPC Routing** forces COPY and UNLOAD traffic through your [[Amazon VPC|VPC]], so VPC controls apply.
- **Materialized views** speed up repeated queries.
- **Workload Management** prioritises query queues.
- **COPY** from [[Amazon S3|S3]] is the fastest bulk load.
