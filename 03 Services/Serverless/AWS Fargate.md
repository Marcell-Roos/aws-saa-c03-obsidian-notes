# AWS Fargate

Serverless compute for containers on [[Amazon ECS]] and [[Amazon EKS]]. You set CPU and memory per task and AWS runs the hosts. It costs more per vCPU than well-used [[Amazon EC2|EC2]], but needs no patching. Fargate Spot is a cheaper option for interruptible tasks. Persistent shared storage comes from [[Amazon EFS]].
