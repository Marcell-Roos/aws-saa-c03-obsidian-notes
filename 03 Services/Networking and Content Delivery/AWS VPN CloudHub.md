# AWS VPN CloudHub

**AWS VPN CloudHub** - provides secure communication between multiple sites, if we have multiple VPN connections. To set it up, we need to connect multiple VPN connections on the same [[AWS Site-to-Site VPN|VGW]], setup dynamic routing and configure [[Internet Gateway and Route Tables|route tables]].
