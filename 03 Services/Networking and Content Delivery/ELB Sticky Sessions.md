# ELB Sticky Sessions

It is possible to implement stickiness so that the same client is always redirected to the same instance behind a [[Elastic Load Balancing|load balancer]]. This works for [[Application Load Balancer|ALB]] and [[Network Load Balancer|NLB]]. It is used to prevent users from losing their session data.

Enabling stickiness may bring imbalance to the load over the backend [[Amazon EC2|EC2 instances]].

For ALB the cookie is used for stickiness. There are two types of cookies:

- **Application-based Cookies**
    - **Custom Cookie** - it is generated by the target. Can include any custom attributes required by the application. Cookie name must be specified individually for each target group (cannot use names AWSALB, AWSALBAPP or AWSALBTG).
    - **Application Cookie** - is is generated by the load balancer and cookie name is AWSALBAPP.
- **Duration-based Cookies** - it is generated by the load balancer. Cookie name is AWSALB.
