# Route 53 Multivalue Routing

It is used when routing traffic to multiple resources. Can be associated with [[Route 53 Health Checks|Health Checks]] (return only values for healthy resources).

Multi-Value is not a substitute for having an [[Elastic Load Balancing|ELB]].
