# IAM Roles Anywhere

> [!note] Exam scope
> Not on AWS's in-scope or out-of-scope list. The in-scope list is non-exhaustive, so treat this as background.

Lets workloads outside AWS get temporary credentials using X.509 certificates, replacing long-lived [[AWS Access Methods|access keys]] on on-premises servers.
