# AWS CloudHSM

Single-tenant hardware security modules in your [[Amazon VPC|VPC]]. You manage the keys and users, and AWS can't access them. HSMs are FIPS 140-2 or 140-3 Level 3 validated in FIPS mode. Deploy at least two across AZs. It can back a [[AWS KMS|KMS]] custom key store. See [[KMS vs CloudHSM]].
