# IAM Access Analyzer

**IAM Access Analyzer** ensures that only intended people have access to our [[Amazon S3|S3 buckets]] (for example: publicly accessible bucket or bucket shared with other AWS account).

It evaluates [[S3 Access Control|S3 Bucket Policies]], S3 ACLs, S3 Access Point Policies.
