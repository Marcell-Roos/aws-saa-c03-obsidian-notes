# AWS Security Hub

Collects findings from [[Amazon GuardDuty]], [[Amazon Inspector]], [[Amazon Macie]] and partner tools into one view, and checks accounts against standards such as CIS and PCI DSS. AWS now calls the posture management product **AWS Security Hub CSPM**. It needs [[AWS Config]] for its checks. Findings can trigger [[Amazon EventBridge]] rules for automated response.
