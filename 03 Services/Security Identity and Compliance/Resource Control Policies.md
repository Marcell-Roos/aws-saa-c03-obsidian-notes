# Resource Control Policies

**RCPs** are organization policies that set the maximum permissions on **resources** in member accounts, whoever is calling. Use them to stop principals outside the organization reaching your resources, even if a [[S3 Access Control|bucket policy]] is too open. **Declarative policies** enforce service configuration across accounts. See [[SCPs vs RCPs vs Permission Boundaries]].
