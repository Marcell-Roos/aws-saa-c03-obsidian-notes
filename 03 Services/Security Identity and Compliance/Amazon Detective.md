# Amazon Detective

Analyses and visualises security data to find the **root cause** of a finding. It builds a graph from [[AWS CloudTrail|CloudTrail]], [[VPC Flow Logs]] and [[Amazon GuardDuty|GuardDuty]] data. GuardDuty detects, Detective investigates.
