# IAM Security Tools

- **[[AWS IAM|IAM]] Credential Report** (**account-level**) - Report that lists all account’s users and the status of their credentials.

- **IAM Access Advisor** (**user-level**) - Shows the service permissions granted to a user and when those services were last accessed. This information can be used to revise policies.

Best practice: use the credential report for an account-wide audit, and Access Advisor for per-identity last-used data.
