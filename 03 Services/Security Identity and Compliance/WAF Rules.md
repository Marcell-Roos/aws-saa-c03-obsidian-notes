# WAF Rules

A **web ACL** holds rules evaluated in priority order.

- **IP sets** allow or block address ranges.
- **Geo-match** rules act by country.
- **Rate-based rules** limit requests per IP.
- **AWS Managed Rules** cover common threats such as SQL injection and XSS.
- **Rule groups** are reusable bundles.
