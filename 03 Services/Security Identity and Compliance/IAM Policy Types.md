# IAM Policy Types

| Type | Attached to | Notes |
| --- | --- | --- |
| AWS managed | Identities | Maintained by AWS |
| Customer managed | Identities | Reusable, versioned, preferred |
| Inline | One identity | Deleted with the identity |
| Resource-based | A resource | Has a Principal element |
