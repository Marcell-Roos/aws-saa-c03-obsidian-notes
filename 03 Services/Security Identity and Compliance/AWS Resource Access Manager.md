# AWS Resource Access Manager

Shares resources across accounts or an organization without copying them. Common examples are [[Amazon VPC|VPC]] subnets, Transit Gateways, [[Route 53 Resolver]] rules and [[AWS License Manager|License Manager]] configurations.
