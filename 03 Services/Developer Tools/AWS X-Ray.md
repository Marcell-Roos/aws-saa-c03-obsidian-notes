# AWS X-Ray

Traces requests through distributed applications, shows a service map, and pinpoints latency and errors. Pick it for "find which [[Microservices|microservice]] is slow". [[Amazon CloudWatch]] gives metrics and logs, while X-Ray gives per-request traces.
