# Amazon MemoryDB

> [!note] Exam scope
> Not on AWS's in-scope or out-of-scope list. The in-scope list is non-exhaustive, so treat this as background.

Durable in-memory database with Redis and Valkey compatibility. Use it as a primary database, while [[Amazon ElastiCache]] is a cache.
