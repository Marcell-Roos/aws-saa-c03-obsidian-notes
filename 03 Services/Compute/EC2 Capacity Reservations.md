# EC2 Capacity Reservations

- **Capacity Reservations**: reserve capacity in a specific AZ for any duration.

    Reserve On-Demand instances capacity in a specific AZ for any duration. We always have access to [[Amazon EC2|EC2]] capacity when we need it. No time commitment and no billing discounts. To benefit from billing discounts we can combine it with Regional [[EC2 Reserved Instances|Reserved Instances]] and Saving Plans.

    We are charged at On-Demand rate whether we run instances or not.

    Suitable for short-term, uninterrupted workloads that needs to be in a specific AZ.
