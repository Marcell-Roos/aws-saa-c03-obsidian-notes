# EC2 Instance Connect

**EC2 Instance Connect** is a feature that allows us to connect to our [[Amazon EC2|EC2 instances]] without needing to manage SSH key. The user must have the necessary [[AWS IAM|IAM]] permissions to use EC2 Instance Connect.

It reduces the risk associated with managing long-term SSH keys.
