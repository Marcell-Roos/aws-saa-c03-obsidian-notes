# AWS Batch

**AWS Batch** is a fully managed batch processing service at any scale (efficiently runs 100 000s of computing batch jobs on AWS). A batch job is a job with a start and an end.

Batch jobs are defined as Docker images and run on [[Amazon ECS|ECS]]. Batch will dynamically launch [[Amazon EC2|EC2 instances]] or [[EC2 Spot Instances|Spot Instances]] and will provision the right amount of compute/memory.
