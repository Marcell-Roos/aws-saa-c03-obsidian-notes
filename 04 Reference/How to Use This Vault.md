# How to Use This Vault

The short answer is to open the [[Study Guide]] and follow it from top to bottom. This page explains how the vault is laid out.

## Layout

| Folder | What is in it |
| --- | --- |
| `00 Study Guide` | The step-by-step plan, and your [[Mistake Log]] |
| `01 Exam` | The exam overview, four domain pages, exam technique and the final cheat sheet |
| `02 Topics` | 31 chapters, numbered in study order |
| `03 Practice` | Five full practice exams and the hands-on labs |
| `04 Reference` | Service index, lifecycle status, sources, corrections and licences |

## How a chapter is built

Almost every chapter follows the same pattern:

1. **Why this matters:** the exam tasks it covers and a time estimate.
2. **The content:** explained in plain language, with tables and diagrams.
3. **Exam patterns:** a table that turns question wording into answers.
4. **Check yourself:** exam-style questions with hidden answers.

Each topic now has one chapter, so a section such as S3 lifecycle rules is a heading in a chapter, not a separate note. Older note names still work in the quick switcher (Ctrl+O), because they are saved as aliases of the chapter that absorbed them.

## Answers are hidden

Answers sit in folded callouts, which appear collapsed in Reading view and Live Preview. Click the arrow to open one. In Source mode they are visible, so avoid that mode when you are testing yourself.

## Graph view

Open the graph with Ctrl+G. Chapters are coloured by subject, and links show how topics depend on each other. With fewer, larger notes, the graph is much simpler than before.

Useful filters:

- `tag:#topic` shows only the chapters.
- `path:"03 Practice"` shows only the practice material.
- `-path:"04 Reference"` hides the reference notes.

## Tags

| Tag | Meaning |
| --- | --- |
| `topic` | A study chapter |
| `exam` | Exam guidance |
| `practice` | Practice exams |
| `reference` | Reference material |
| `cat/...` | The subject area of a chapter |
| `scope/in` | Relevant to the exam |

Inside chapters, services that are out of scope, retired or closed to new customers are flagged in the text.

## Keeping it current

AWS changes quickly, and this vault was checked on 1 November 2026. The [[Corrections Log]] and [[Sources]] record what was checked and how. Before your exam, take a quick look at the [exam guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html) to see if anything has changed.
