# How to Use This Vault

## Graph view
Open the graph (Ctrl+G). Colours are set by folder:

- **Exam pages and tasks** are the outer hubs that show what the exam wants.
- **Maps** group services by category.
- **Service notes** are coloured by category, so clusters such as storage or networking stand out.
- **Comparisons, concepts and architectures** sit between clusters and show how they connect.

Useful filters in the graph search box:

- `tag:#scope/in` shows only exam-relevant notes.
- `path:"01 Exam/Tasks"` shows one domain's study path when you follow links out.
- `-path:"01 Exam/Drills"` hides drills if the graph gets busy.

For a single topic, open a note and use **Open local graph** with depth 2.

## Note types
- **Small linking files** are the Maps, Domains and Tasks. They hold links and very little text.
- **Service notes** cover one service or feature each.
- **Drills** are exam-style scenarios and keyword tables for active recall.

## Tags
- `scope/in`: in scope or a feature of an in-scope service.
- `scope/unlisted`: on neither AWS list.
- `scope/out`: on AWS's out-of-scope list.
- `scope/retired`: shut down or being shut down. Kept because older practice questions still mention it.
