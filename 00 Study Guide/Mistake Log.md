# Mistake Log

Every wrong answer is a free lesson. Add a row for each question you miss in a self-test or practice exam, and for each one that you got right by guessing.

## How to use it

1. Write what the question was really testing, in a few words.
2. Choose a reason from the list below.
3. Write the one fact or rule that would have got you the mark.
4. Go back to the chapter, and read that section again.
5. Redo the question in a few days. Write **Yes** under **Fixed** only when you get it right and can explain why the other options are wrong.

## Reasons for a wrong answer

| Code | Reason | What to do |
| --- | --- | --- |
| **K** | I did not know the fact | Reread the section |
| **C** | I confused two services | Find the comparison table and learn the difference |
| **R** | I misread the question or missed a word | Slow down, and read the last sentence first |
| **Q** | I ignored the qualifier | Practise with the table in [[Exam Technique]] |
| **O** | I overthought it | Trust the simplest option that meets the requirements |
| **T** | I ran out of time | Practise flagging at 90 seconds |

If most of your mistakes have the code R or Q, your knowledge is fine, and your technique needs the work.
