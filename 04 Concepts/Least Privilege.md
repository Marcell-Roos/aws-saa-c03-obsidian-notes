# Least Privilege

Grant only the permissions a task needs. Start small, then widen as required.

- Use roles and temporary credentials instead of long-lived [[AWS Access Methods|access keys]].
- Use [[IAM Access Analyzer]] and [[IAM Security Tools]] to find unused access.
- Use [[IAM Permission Boundaries]] and [[Service Control Policies]] to cap what's possible.
