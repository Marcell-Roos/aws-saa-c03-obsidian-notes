# Microservices

Small, independently deployable services, each owning its data and communicating through APIs or events.

- **Synchronous:** [[Amazon API Gateway]], [[Application Load Balancer]]
- **Asynchronous:** [[Amazon SQS]], [[Amazon SNS]], [[Amazon EventBridge]], [[Amazon Kinesis]]
- **Compute:** [[AWS Fargate]], [[AWS Lambda]], [[Amazon ECS]], [[Amazon EKS]]

See [[Case Study Microservices]].
